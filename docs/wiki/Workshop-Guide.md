# Workshop guide

A practical outline for an **Oslo Laptop Orchestra** session using the [web hub](https://fourms.github.io/olo/).

## Before the room

- [ ] Confirm **GitHub Pages** site loads: [fourms.github.io/olo](https://fourms.github.io/olo/)
- [ ] Room has power and space for **one laptop + speakers per person**
- [ ] Agree: **no house PA** — only sound from each laptop’s speakers
- [ ] Optional: same Wi‑Fi if you use **Host sync** in CliX or Crystalis

## Setup (10 min)

1. Everyone opens the hub and chooses an instrument (or assign roles: drones, rhythm, melody, texture).
2. **Audio on** on each machine — first click must be a user gesture.
3. Set laptop volume to **70% or higher**; angle speakers toward the group.
4. Mic apps (**Clap Hands**, **Munge**): allow microphone when prompted; use **Chrome** or **Firefox** over HTTPS (GitHub Pages is fine).

## Suggested first session (45 min)

| Time | Activity |
|------|----------|
| 5 min | Demonstrate the **three rules**; one person plays **Green Button** or **Droner** |
| 10 min | All on **CliX** — Host starts sync; explore holding different keys |
| 10 min | Split: half **Crystalis** (bow), half **Tap Bloom** (texture) |
| 10 min | **Clap Hands** or **Munge** — call-and-response across the circle |
| 10 min | Free mix — same piece, different apps; conductor cues (hands only) |

## Roles (like a traditional orchestra)

| Role | Apps | Listening job |
|------|------|----------------|
| Bass / drone | Droner, Green Button | Anchor pitch; leave space |
| Rhythm | CliX | Lock to grid; don’t crowd |
| Melody | Crystalis | Lines above the drone |
| Texture | Tap Bloom, Clap Hands, Munge | Punctuation and bloom |

## Troubleshooting

| Problem | Try |
|---------|-----|
| No sound | **Audio on**; raise app volume slider; check mute |
| Mic silent | Permission granted? Reload after allowing |
| CliX out of sync | Everyone on the **same musician link** from Host |
| Harsh room | Fewer Munge / Clap Hands feedback; more Droner |
