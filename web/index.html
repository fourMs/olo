Oslo Laptop Orchestra

Web Audio instruments for laptop performances

Browser instruments

Each performer opens one instrument in Chrome or Firefox, turns Audio on, and plays through the laptop speakers — no external PA, following OLO’s extended-instrument rule.

These apps port classic OLO ChucK and Max/MSP pieces from patches/, plus laptop-friendly versions of selected OMO mobile instruments.

Ensemble sync: CliX and Crystalis include a Host tab — share the musician link so everyone shares the same grid clock (replaces the old ChucK server-multi.ck).

Historical patches live in patches/. This web/ folder is the modern performance path — keyboard, pointer, and microphone only.
